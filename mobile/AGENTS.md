# Expo HAS CHANGED

Bu proje **Expo SDK 54** kullanıyor (telefonun Expo Go sürümü SDK 54 desteklediği için 56'dan düşürüldü).
Kod yazmadan önce ilgili sürümün dokümanlarını oku: https://docs.expo.dev/versions/v54.0.0/

Notlar:
- Yeni kütüphane eklerken `npx expo install <paket>` kullan (SDK 54 ile uyumlu sürümü seçer).
- `react-native-webview` Expo Go'da gömülü gelir → ekstra dev-build gerekmez.
